# Quick Task Summary: settings-pages-clinical-palette-from-report-editor

Brought the ReportEditor's clinical-workstation palette to every Settings surface so the app reads as one product, not two. SettingsLayout now sits on warm ivory `#F7F1E6` with a 4px teal signature stripe anchoring the inner content card; SettingsSidebar uses the same `#EFEAE0` panel tint as the ReportEditor screenshots rail; every Settings card uses `#FBF7EE` ivory with `#E0D9C6` hairline borders and the soft 2-layer shadow; CardTitles get the small-caps teal eyebrow (`text-[11px] uppercase tracking-[0.18em] text-[#0E3A47]`); every `<Input>` / SelectTrigger carries ReportEditor's FIELD_CLASS; primary CTAs (Save / Add user / Apply / Load .lic / Create backup / Add device) drop into the deep teal `#0E3A47` so each page reads as a clinical chart rather than a SaaS dashboard.
