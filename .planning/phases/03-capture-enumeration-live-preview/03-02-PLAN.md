<objective>
Ship both renderer capture surfaces and the shared preview lifecycle: Settings → Capture for persistent configuration verified by a live preview, Procedure Room for a session-only preview with disabled Record, and the bridge between main-side dshow-canonical device names and renderer-side browser media deviceIds so `getUserMedia` always receives a valid browser deviceId.

Purpose: Give a doctor a real, safe way to validate a USB capture source before Phase 4 recording exists, while keeping two deviceId namespaces correct (dshow for Phase 4 ffmpeg, browser for Phase 3 getUserMedia).

Output: Reusable preview hook, device-map hook, routes, settings configuration page, procedure-room hero, previousRoute tracking, no-device audit hook, and renderer tests for lifecycle, deviceId bridging, and locked UX decisions.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Renderer → MediaDevices | Browser permission and `MediaDeviceInfo.deviceId` open hardware. The browser deviceId is the ONLY value passed to `getUserMedia` (BLOCKER 1). |
| Renderer → IPC | Renderer-selected canonical names cross to main; main derives `doctorId` from session (BLOCKER 4). |
| Route lifecycle → OS media handle | Unmount / navigation / Finish must release every `MediaStreamTrack`. |
| Empty-state render → main audit sink | Renderer fires `noDeviceAudit`; main records the audit row and treats the event as a marker, not a state change. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-3-07 | Denial of Service | `useVideoPreview` | high | mitigate | Stop every `MediaStreamTrack` on Stop, Finish, device change, cancellation, and unmount; never retain a stream after route exit. |
| T-3-08 | Tampering | ProcedureRoom device override | medium | mitigate | Override is component-local; Procedure Room picker omits all persistence IPC; Settings Save is the only default mutation path. |
| T-3-09 | Information Disclosure | preview video element | medium | mitigate | `muted`, `playsInline`, and `audio:false`; no audio stream or recording output is created. |
| T-3-10 | Tampering | `useCaptureDeviceMap` bridge | medium | mitigate | Bridge matches by case-insensitive trimmed label only; falls back to raw label when no match — no silent bridge to a wrong deviceId. |
| T-3-11 | Elevation of Privilege | Save payload shape | high | mitigate | `setDefaultDevice` / `setPreset` renderer payloads do NOT include `doctorId` (compile-time enforced by TS contract); main derives from `requireSession()`. |
| T-3-12 | Repudiation | no-device state | low | mitigate | `noDeviceAudit` is fired exactly once per empty-state mount and produces a `capture.no_device` audit row. |
| T-3-SC | Tampering | npm installs | high | mitigate | No new packages in this plan; package gate remains covered by 03-01. |
</threat_model>
