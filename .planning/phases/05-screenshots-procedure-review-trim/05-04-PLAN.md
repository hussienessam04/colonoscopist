        1. Parse the Range header. Use a regex `/^bytes=(\d*)-(\d*)$/`. Reject malformed ranges (e.g. `bytes=abc-def`) by falling back to the full 200 response.
        2. Compute `start = parseInt(parts[1])`. Compute `end = parts[2] === '' ? stat.size - 1 : parseInt(parts[2])`.
        3. Clamp: `start = Math.max(0, Math.min(start, stat.size - 1))`. `end = Math.max(start, Math.min(end, stat.size - 1))`.
        4. If `start > end`, return `416 Range Not Satisfiable` with `Content-Range: bytes */<size>`.
        5. Otherwise return `206 Partial Content` with `Content-Range: bytes <start>-<end>/<size>` + `Content-Length: <end - start + 1>` + `createReadStream(filePath, { start, end }).pipe(res)`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Renderer -> `<video>.src` URL | The URL is composed from `mediaUrl + '/media/' + patientId + '/' + procedureId + '/' + filename`. The PreviewServer validates the path components with a strict regex + `path.relative()` escape check. |
| Renderer -> `<video>` element seek | Chromium issues `Range: bytes=<start>-` requests when seeking. The PreviewServer's `/media/` route parses + responds with `206 Partial Content`. |
| Main -> `<video>` element full file | The route returns `200 OK` + the full file when no Range header is present. |
| Main -> audit_log | `procedure.trimmed` + `procedure.restored` rows are written in the same transaction as the data mutation; metadata is bounded (userData-relative paths). |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-33 | Tampering | Range request header injection | medium | mitigate | The Range handler parses `bytes=<start>-<end>` with a strict regex; malformed headers fall back to the full 200 response. Out-of-bounds ranges clamp to `stat.size`. |
| T-05-34 | Tampering | Range request path-escape (e.g. `/media/..%2F..%2Fetc/passwd`) | high | mitigate | The path-escape protection (regex + `path.relative()` check) is the canonical guard. URL-encoded path-escape attempts (\`%2F\`) are REJECTED by the regex `/^/media/([a-zA-Z0-9-]+)/([a-zA-Z0-9-]+)/([\w.-]+)$/` because `\w.` doesn't match `/`. The audit log records the attempt. |
| T-05-35 | Denial of Service | Range request large file read | low | mitigate | The route uses `createReadStream(filePath, { start, end })` — Node streams chunks at a time. The renderer can't request arbitrary byte ranges (the handler clamps `start` and `end` to `stat.size`). |
| T-05-36 | Denial of Service | Null byte injection in path | high | mitigate | The regex `/^[a-zA-Z0-9-]+$/` rejects null bytes in path segments. The handler returns 400 for malformed paths. |
| T-05-37 | Tampering | Range request start > end | low | mitigate | The handler returns `416 Range Not Satisfiable` with `Content-Range: bytes */<size>`. The `<video>` element re-issues a valid range request on seek. |
| T-05-38 | Denial of Service | Range request with negative start | low | mitigate | `Math.max(0, start)` clamps the start to 0. The handler returns `206 Partial Content` with the byte slice from 0 to the requested end. |
| T-05-39 | Denial of Service | Trim subprocess timeout | low | mitigate | The `applyTrim` function has a 5-minute timeout that kills the ffmpeg subprocess via SIGTERM. The IPC handler surfaces `IPC_VALIDATION` with the timeout message. The renderer UI shows the timeout in the error toast. |
| T-05-40 | Tampering | Media server port collision | low | mitigate | The media server is bound to `127.0.0.1:0` (OS-assigned port). The `getMediaUrl()` IPC returns the actual bound port — no hardcoded port. The OS port allocation is collision-free. |
| T-05-41 | Information Disclosure | `<video>` element URL leaks procedureId | low | mitigate | The URL contains `patientId + procedureId + filename` — these are not PII (procedureId is a UUID). The URL is `127.0.0.1` (localhost only); the renderer never sends the URL to a remote server. |
| T-05-42 | Tampering | Range request with very large end | low | mitigate | `Math.min(end, stat.size - 1)` clamps the end to `stat.size - 1`. The handler returns `206 Partial Content` with the byte slice from start to the file end. |
| T-05-43 | Elevation | Media server access from other origins | low | mitigate | The server is bound to `127.0.0.1` (localhost only). External origins can't reach the server. The CORS headers are not set (the server is same-origin for the renderer's `<video>` element). |
| T-05-SC | Tampering | npm/pip/cargo installs | high | mitigate | slopcheck + blocking human checkpoint for `[ASSUMED]`/`[SUS]` packages. Plan 04 adds NO new dependencies. |
