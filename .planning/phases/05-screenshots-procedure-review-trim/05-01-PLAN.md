## Trust Boundaries

| Boundary | Description |
|---|---|
| Renderer -> screenshots.add IPC | Untrusted renderer sends a base64-encoded JPEG; main validates payload size and decodes server-side. |
| Renderer -> procedures.trim / procedures.restore | IPC surface declared in Plan 01 but the handlers are stubs returning `IPC_NOT_IMPLEMENTED`. Plan 03 fills the gate with the partial-status check + range validation. |
| Main -> filesystem `<userData>/data/media/patients/<p>/<proc>/screenshots/<ts>.jpg` | The IPC handler is the ONLY writer (cap rule). Per Anti-Pattern 2, the DB stores the userData-relative path; the absolute path is resolved at read time. |
| Main -> audit_log | `screenshot.captured` + `screenshot.deleted` + `screenshot.annotation_updated` rows are written in the same transaction as the data mutation; metadata fields are bounded. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-05-01 | Tampering | Renderer spoofs `timestampInVideoMs` | medium | mitigate | `safeParse` enforces `z.number().int().nonnegative()`; the renderer cannot inject a negative or non-integer value. The server-side `currentMs` is the source of truth for the post-recording path; the renderer just relays. Mid-procedure `Date.now() - startedAt` is bounded by the server's `started_at` (a renderer-spoofed startedAt would not match the row). |
| T-05-02 | Elevation | Cross-patient screenshot delete | high | mitigate | `screenshots.delete` is keyed on `id` (the row PK), not `procedureId`. The repo's `delete(id)` looks up the row first; if the row's `procedure_id` references a patient the doctor is not authorized for, the IPC handler rejects `IPC_NOT_FOUND`. | T-05-03 | Denial of Service | Oversized JPEG payload | high | mitigate | `safeParse` enforces `jpegBase64 ≤ 8_000_000` chars; the IPC handler's `Buffer.byteLength` check rejects < 2 KB or > 6 MB decoded. The disk-usage DoS surface is bounded; the JS heap is bounded by the base64 cap. |
| T-05-04 | Information Disclosure | Audit metadata leaks procedure identifiers | low | mitigate | `screenshot.captured`'s metadata is `{ screenshotId, timestampInVideoMs }` only — no absolute paths, no patient identifiers, no procedure content (Fix 6 inheritance).
