## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer -> MediaServer /media/ (CORS preflight + GET) | The renderer at localhost:vite or file:// requests an mp4 from 127.0.0.1:port. Without CORS headers on the response, Chromium refuses the cross-origin load. With Access-Control-Allow-Origin on the server AND crossOrigin=anonymous on the client, Chromium accepts and renders the video clean. |
| Renderer -> PreviewServer /preview (MJPEG stream) | The renderer at localhost:vite or file:// requests the live MJPEG multipart stream from 127.0.0.1:previewPort. Same CORS requirement; without the header the img loads in no-cors mode and any subsequent drawImage taints the canvas. |
| Renderer -> capture-screenshot lib | The library calls canvas.drawImage then canvas.toBlob. happy-dom + jsdom do not enforce Chromium tainted-canvas security guard; the unit suite monkey-patches toBlob to a permissive stub. The new contract-guard test (Task 2) introduces a Chromium-equivalent rejection on uncrossed sources so the contract is enforced at the test layer. |
