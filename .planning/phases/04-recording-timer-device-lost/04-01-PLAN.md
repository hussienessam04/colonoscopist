<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Renderer -> procedures/recording IPC | Untrusted renderer payloads cross contextBridge. `doctorId` is NEVER accepted from the renderer; every handler derives it from `requireSession()` (BLOCKER 4 inheritance). |
| ffmpeg stderr -> main parser | External process output parsed before becoming authoritative state. |
| Main -> SQLite procedures/procedure_notes/procedure_segments | Main-only persistence; absolute paths never stored (Anti-Pattern 2). |
| ffmpeg asar binary -> execution | ffmpeg-static is unbundled from the asar archive via `build.asarUnpack`; `defaultFfmpegPath()` rewrites `app.asar` -> `app.asar.unpacked` once. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-01 | Tampering | `procedures.create` / `recording.start` IPC | high | mitigate | `doctorId` derived from `requireSession()` exclusively; `procedures.create` payload accepts only `{ patientId }` and inserts with session doctorId; `recording.start` derives doctorId from `requireSession()` and canonicalizes the deviceId via `canonicalizeOrThrow` BEFORE the proceduresRepo insert. |
| T-04-02 | Denial of Service | ffmpeg child process | high | mitigate | One child per procedureId via `RecorderRegistry.set` (throws `RecorderBusyError` on duplicate); stdin `q\n` + 5 s SIGTERM grace + SIGKILL fallback is the only stop path (no renderer access to raw child); `fs.fsyncSync` on the open fd before close (PITFALLS §1). |
| T-04-03 | Information Disclosure | `video_path` storage | medium | mitigate | Path is stored relative to userData (`'data/media/patients/<patientId>/<procedureId>/video.mp4'`); resolved at read time via `path.join(app.getPath('userData'), storedRelPath)` (Anti-Pattern 2). |
| T-04-04 | Repudiation | recording audit writes | high | mitigate | Every `recording.started` / `recording.stopped` event writes one `audit_log` row with `metadata.deviceName === <canonical-form>` and `metadata.preset === <PresetSummary>`; mutation + audit in one `db.transaction()` so a rollback is consistent (per AUDIT-01 + Fix 6 inheritance). |
| T-04-05 | Tampering | Electron webPreferences | high | mitigate | Existing five flags (`contextIsolation`, `nodeIntegration`, `sandbox`, `webSecurity`, `permissions: ['media']`) unchanged; security baseline test (`tests/shell/security-baseline.test.ts`) continues to pass. |
| T-04-06 | Tampering | ffmpeg-static packaging | medium | mitigate | Single `build.asarUnpack` entry; `defaultFfmpegPath()` throws with diagnostic string when the resolved binary is missing — fails fast at first spawn instead of producing a 0-byte mp4 (PITFALLS §1 + SKILL §2). |
| T-04-07 | Repudiation | unauthenticated audit pollution | medium | mitigate | All `procedures.*` and `recording.*` IPC handlers gate on `requireSession()` before touching the DB or audit table; `scanForOrphans` appends audit rows from the main process at startup (no renderer can suppress the audit). |
