<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Renderer -> recording.pause/resume IPC | Untrusted renderer triggers pause/resume; gate on `requireSession()` (T-04-07 inheritance). |
| ffmpeg concat subprocess | Spawned by main with injectable `deps.spawn`; arguments hard-coded via `buildConcatArgs` (renderer cannot inject). |
| procedure_segments UNIQUE constraint | DB layer prevents duplicate segment_index per procedure (T-04-XX); IPC surfaces unique-violation as `IPC_VALIDATION`. |
| Renderer Zustand store freeze | The `useTimerSnapshot` selector only reads the `displayMs` derivation; no caller can bypass the freeze by reading `Date.now()` directly. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04-12 | Tampering | `recording:pause/resume` IPC | medium | mitigate | Renderer cannot pass a `procedureId` (the registry indexes the active procedure); `requireSession()` gate before forwarding to supervisor; the supervisor state machine rejects out-of-order transitions (e.g. `resume` from `'idle'` throws). |
| T-04-13 | Denial of Service | concat subprocess | medium | mitigate | ffmpeg concat is bounded by `segments.length` (limit per Pause cycle is bounded by renderer doctor behavior); `buildFfmpegArgs` + `buildConcatArgs` are pure functions (no shell-string interpolation that could allow injection); `windowsVerbatimArguments: true` keeps the args array literal. |
| T-04-14 | Tampering | procedure_segments UNIQUE | low | mitigate | DB-layer UNIQUE constraint on `(procedure_id, segment_index)` enforces monotonic ordering; duplicate inserts throw `SQLITE_CONSTRAINT_UNIQUE` -> `IPC_VALIDATION`. |
| T-04-15 | Information Disclosure | segment file paths | low | mitigate | Stored as relative paths (e.g. `'data/media/patients/<pid>/<procId>/video-seg0.mp4'`); resolved at read time via `path.join(app.getPath('userData'), storedRelPath)` (Anti-Pattern 2). |
| T-04-16 | Repudiation | pause/resume audit writes | medium | mitigate | Each pause writes `recording.paused` with `metadata.segmentIndex`; each resume writes `recording.resumed` with the next segmentIndex; the finalize `recording.stopped` audit carries `metadata.segmentCount` so the audit log fully reconstructs the segment timeline without scanning `procedure_segments`. |
