**Fix 1 — Shape editing after commit (ScreenshotCropModal.tsx):**

State changes:
- Keep `finalPolygon: {x, y}[]` (already exists from Plan 16)
- Add `draggingVertex: number | null` (which vertex index is being dragged)
- Add `draggingShape: boolean` (true when user is dragging the interior to move)
- Add `dragOffset: {dx, dy}` for shape-drag offset

Replace the existing mouse handlers with this flow:

```tsx
function handleMouseDown(e): void {
  const { x, y } = canvasToImage(e);
  
  if (mode === 'rectangle' && !finalPolygon.length) {
    // Start new rectangle drag
    setRectStart({ x, y });
    setRectEnd({ x, y });
  } else if (mode === 'freehand' && !finalPolygon.length) {
    setFreehandPath([{ x, y }]);
  } else if (finalPolygon.length) {
    // Existing shape — check what was clicked
    const vertexIdx = hitTestVertex(x, y, finalPolygon);
    if (vertexIdx >= 0) {
      setDraggingVertex(vertexIdx);
    } else if (pointInPolygon(x, y, finalPolygon)) {
      // Click inside shape — start drag-to-move
      setDraggingShape(true);
      setDragOffset({ dx: 0, dy: 0 }); // will be set on first move
      setDragStart({ x, y });
    }
  }
}

function handleMouseMove(e): void {
  const { x, y } = canvasToImage(e);
  
  if (draggingVertex !== null) {
    // Move the vertex, snap to image bounds
    const clamped = { x: clamp(x, 0, imgSize.width), y: clamp(y, 0, imgSize.height) };
    setFinalPolygon(p => p.map((pt, i) => i === draggingVertex ? clamped : pt));
  } else if (draggingShape) {
    // Translate the entire shape
    const newPolygon = finalPolygon.map(pt => ({
      x: clamp(pt.x + (x - dragStart.x), 0, imgSize.width),
      y: clamp(pt.y + (y - dragStart.y), 0, imgSize.height),
    }));
    setFinalPolygon(newPolygon);
    setDragStart({ x, y });
  } else if (mode === 'rectangle' && rectStart) {
    setRectEnd({ x, y });
  } else if (mode === 'freehand' && freehandPath.length > 0) {
    // existing sampling logic
  }
}

function handleMouseUp(): void {
  if (mode === 'rectangle' && rectStart && rectEnd && !finalPolygon.length) {
    // Commit rectangle → polygon
    const polygon = rectToPolygon(rectStart, rectEnd);
    if (polygonArea(polygon) >= 100) setFinalPolygon(polygon);
    setRectStart(null);
    setRectEnd(null);
  } else if (mode === 'freehand' && freehandPath.length >= 3 && !finalPolygon.length) {
    setFinalPolygon(freehandPath);
    setFreehandPath([]);
  } else if (mode === 'polygon' && !draggingShape) {
    // Add vertex in polygon mode
    if (polygonMode) setFinalPolygon(p => [...p, { x, y }]);
  }
  setDraggingVertex(null);
  setDraggingShape(false);
}
```

**Fix 2 — Live preview after crop (ScreenshotLightbox.tsx):**

Apply the same blob-URL pattern that ScreenshotCropModal uses:

State changes:
- Add `imageUrl: string | null` (blob URL for the current screenshot)
- Add `cacheBuster: number` (increment after crop to force reload)

Effects:
- On mount + when screenshot prop changes: fetch blob via IPC, create blob URL with `?v=${cacheBuster}`, set as imageUrl
- On unmount + when screenshot changes: revoke the previous blob URL
- The `<img>` src becomes `imageUrl`

After successful crop callback:
- Increment `cacheBuster` (forces new blob fetch + new URL)
- The image refreshes with the cropped bytes

```tsx
useEffect(() => {
  if (!screenshot) return;
  let cancelled = false;
  let currentUrl: string | null = null;
  (async () => {
    const result = await window.api.screenshots.getBlob({ id: screenshot.id });
    if (cancelled) return;
    if (result.ok) {
      const bytes = new Uint8Array(result.bytes);  // already Uint8Array from IPC
      const blob = new Blob([bytes], { type: result.mimeType });
      currentUrl = URL.createObjectURL(blob);
      setImageUrl(currentUrl);
    }
  })();
  return () => {
    cancelled = true;
    if (currentUrl) URL.revokeObjectURL(currentUrl);
  };
}, [screenshot?.id, cacheBuster]);
```

The existing `onCroped` callback now also needs to bump cacheBuster:
```tsx
const handleCroped = (newDims, byteSize) => {
  setCacheBuster(Date.now());  // force image reload
  onCroped?.(newDims, byteSize);
};
```

This way after a successful crop, the lightbox image immediately reflects the new bytes from disk.
