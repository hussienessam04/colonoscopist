<objective>
Make screenshot crop easier by adding a Rectangle | Free-hand mode toggle. User selects a mode then drags once — Rectangle mode draws a rect in one drag, Free-hand mode samples a path along the cursor. Both feed the existing polygon→bbox crop pipeline. The multi-click "add vertices one at a time" flow stays as a 3rd mode (Polygon) for advanced use.

Why this matters: doctors want speed. The current "click-click-click" for each polygon vertex is tedious for routine crops where a rectangle is fine. Rectangle mode = one drag for 80% of clinical crops. Free-hand mode = continuous path for irregular polyp boundaries. Polygon mode stays available for precise manual control.

</objective>

Replace the existing canvas mouse handlers with mode-aware handlers:

```tsx
function handleMouseDown(e: React.MouseEvent<HTMLDivElement>): void {
  const { x, y } = canvasToImage(e); // existing conversion helper
  if (mode === 'rectangle') {
    setRectStart({ x, y });
    setRectEnd({ x, y });
  } else if (mode === 'freehand') {
    setFreehandPath([{ x, y }]);
  }
  // 'polygon' mode: existing click-to-add logic
}

function handleMouseMove(e: React.MouseEvent<HTMLDivElement>): void {
  if (mode === 'rectangle' && rectStart) {
    setRectEnd(canvasToImage(e));
  } else if (mode === 'freehand' && freehandPath.length > 0) {
    const { x, y } = canvasToImage(e);
    const last = freehandPath[freehandPath.length - 1];
    // Only add if moved enough distance (avoid too many points)
    const dx = x - last.x;
    const dy = y - last.y;
    if (Math.sqrt(dx * dx + dy * dy) >= 5) {
      setFreehandPath([...freehandPath, { x, y }]);
    }
  }
}

function handleMouseUp(): void {
  if (mode === 'rectangle' && rectStart && rectEnd) {
    const x = Math.min(rectStart.x, rectEnd.x);
    const y = Math.min(rectStart.y, rectEnd.y);
    const width = Math.abs(rectEnd.x - rectStart.x);
    const height = Math.abs(rectEnd.y - rectStart.y);
    if (width >= 10 && height >= 10) {
      // Convert rect to polygon (4 corners) for unified IPC contract
      const polygon = [
        { x, y },
        { x: x + width, y },
        { x: x + width, y: y + height },
        { x, y: y + height },
      ];
      setFinalPolygon(polygon);
    }
  } else if (mode === 'freehand' && freehandPath.length >= 3) {
    setFinalPolygon(freehandPath);
  }
  // Reset transient state
  setRectStart(null);
  setRectEnd(null);
}
```
