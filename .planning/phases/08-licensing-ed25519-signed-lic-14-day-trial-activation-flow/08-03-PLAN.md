<objective>
Wire the `licenseGated` IPC gate helper around every `ipcMain.handle` registration so the app enforces license validity at the IPC boundary, not in each handler. The gate has a narrow exemption list (auth + license + audit) so the app can boot, log in, activate, AND log audit-on-every-read regardless of license state; every other channel returns `{ ok: false, code: 'IPC_LICENSE_INVALID' | 'IPC_LICENSE_EXPIRED' }` when the license is missing or expired.

Purpose: Closes LIC-04 verbatim ("All IPC handlers are gated by license validity; license is enforced at the boundary, not in each handler"). Without this plan, the verify path (Plan 01) + trial clock (Plan 02) compute license state but nothing in the IPC layer actually consults it.

Output: `gate.ts` module + EXEMPT_CHANNELS set + wrap every existing `register*()` call + audit row on gate rejection + 5+ unit tests + RUN_SMOKE=1 integration test that proves `procedures.create` is blocked when unactivated.
</objective>

    **1. Create `src/main/license/gate.ts`:**

    Follow RESEARCH §Pattern 2 exactly:

    ```
    // Phase 8 / Plan 03 — IPC gate (LIC-04 + D-07 verbatim).
    // Every ipcMain.handle() registration is wrapped with `licenseGated(channel, handler)`.
    // The wrapper short-circuits when the cached license state is invalid/expired.
    // The exemption list is the minimum to boot, log in, activate, AND log audit-on-every-read.

    import type { IpcMainInvokeEvent } from 'electron';
    import { IPC } from '@shared/ipc-contract';
    import { getLicenseStatus } from './status';
    import { audit } from '../db/audit';

    // Narrow exemption list — minimum needed to boot, log in, activate, AND log audit.
    // AUDIT_LIST + AUDIT_LOG are exempt per CONTEXT D-08: audit-on-every-read continues
    // regardless of license state. AUTH_* are exempt so the login flow can run.
    // LICENSE_* are exempt so the renderer can render the activation modal AND
    // resolve it via LICENSE_ACTIVATE.
    export const EXEMPT_CHANNELS: ReadonlySet<string> = new Set<string>([
      // Auth (the whole flow runs before any license check)
      IPC.AUTH_STATUS,
      IPC.AUTH_BOOTSTRAP,
      IPC.AUTH_WIZARD,
      IPC.AUTH_LOGIN,
      IPC.AUTH_LOGOUT,
      IPC.AUTH_USERS_LIST,
      IPC.AUTH_RECOVERY_REQUEST,
      IPC.AUTH_ACCEPT_RECOVERY_FILE,
      // License self-service (renderer needs to read status + activate)
      IPC.LICENSE_STATUS,
      IPC.LICENSE_ACTIVATE,
      // Audit (workstation-level event log continues regardless of license state)
      IPC.AUDIT_LIST,
      IPC.AUDIT_LOG,
    ]);

    export type LicenseGateError =
      | { ok: false; code: 'IPC_LICENSE_INVALID' }
      | { ok: false; code: 'IPC_LICENSE_EXPIRED' };

    type Handler<P extends unknown[], R> = (
      event: IpcMainInvokeEvent,
      ...args: P
    ) => Promise<R> | R;

    export function licenseGated<P extends unknown[], R>(
      channel: string,
      handler: Handler<P, R>,
    ): Handler<P, R | LicenseGateError> {
      if (EXEMPT_CHANNELS.has(channel)) {
        return handler as Handler<P, R | LicenseGateError>;
      }

      return async (event: IpcMainInvokeEvent, ...args: P): Promise<R | LicenseGateError> => {
        const status = getLicenseStatus();
        if (status.state === 'unactivated') {
          audit({
            action: 'license.gate_rejected',
            entityType: 'license',
            entityId: channel,
            outcome: 'failed',
            userId: null,
            metadata: {
              channel,
              fingerprintHash: status.machineId,
              code: 'IPC_LICENSE_INVALID',
            },
          });
          return { ok: false, code: 'IPC_LICENSE_INVALID' };
        }
        if (status.state === 'expired') {
          audit({
            action: 'license.gate_rejected',
            entityType: 'license',
            entityId: channel,
            outcome: 'failed',
            userId: null,
            metadata: {
              channel,
              fingerprintHash: status.machineId,
              code: 'IPC_LICENSE_EXPIRED',
            },
          });
          return { ok: false, code: 'IPC_LICENSE_EXPIRED' };
        }
        return handler(event, ...args);
      };
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Renderer IPC ↔ main handler | The gate is the FIRST check in every non-EXEMPT channel; renderer cannot bypass it via direct IPC |
| Gate ↔ audit log | Every rejection writes an audit row; audit log is append-only (Phase 2 trigger) |
| EXEMPT list ↔ drift | The EXEMPT set is the only source of truth for which channels bypass the gate; adding a new channel without adding it to EXEMPT defaults to gated (defense-in-depth) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-G01 | Spoofing | Renderer bypasses IPC via direct `ipcRenderer.invoke` of an ungated channel | critical | mitigate | Every non-EXEMPT channel is wrapped; renderer is sandboxed (Phase 1 baseline); the EXEMPT set is the ONLY bypass surface. Plan 06 grep gate (`scripts/check-license-gate.cjs`) catches drift. |
| T-08-G02 | Tampering | Exemption list drift (new IPC channel added in a later phase without updating EXEMPT) | high | mitigate | Defense-in-depth: EXEMPT_CHANNELS is OPT-IN (channels are gated by default). Plan 06 grep gate asserts every `ipcMain.handle` is wrapped. The audit row on every gate rejection surfaces unexpected gate triggers. |
| T-08-G03 | Repudiation | Gate rejection with no audit row | medium | mitigate | Every gate rejection calls `audit({action: 'license.gate_rejected', metadata: {channel, fingerprintHash, code}})` BEFORE returning the error code. The audit log is append-only (Phase 2 trigger). |
| T-08-G04 | Denial of Service | Attacker repeatedly triggers gate rejection to fill audit log | low | accept | The audit log is local-only (Phase 2 design); filling the local log is not a remote DoS. The renderer is the only caller; a malicious renderer would have already bypassed the sandbox baseline (Phase 1), which is a separate threat model. |
| T-08-G05 | Elevation of Privilege | Audit channel added to EXEMPT — but `audit:log` is renderer-side and could be used to flood | low | mitigate | `AUDIT_LOG` is in EXEMPT per CONTEXT D-08 verbatim ("audit-on-every-read continues regardless of license state"). The handler validates `metadata` via zod (existing `auditLogInput` schema); a malicious payload is rejected at the IPC_VALIDATION layer before any row is written. |
| T-08-G06 | Tampering | Trial-state render of "licensed" via in-memory cache poisoning | medium | mitigate | The cache is invalidated only via `invalidateLicenseCache()` (Plan 04 wires this in `loadAndVerifyLicense`). The cache is module-level (not user-editable); the renderer cannot reach it directly. |

## Mitigations implemented by this plan

- **T-08-G01** (renderer bypass): every non-EXEMPT channel is wrapped; renderer is sandboxed; EXEMPT set is the only bypass surface.
- **T-08-G02** (exemption drift): EXEMPT_CHANNELS is OPT-IN; new channels default to gated. Plan 06 grep gate catches drift.
- **T-08-G03** (repudiation): every rejection writes an audit row BEFORE returning the error.
- **T-08-G05** (audit flood): zod-validated `auditLogInput` blocks malformed payloads at the IPC layer.

## Mitigations deferred to later plans

- **T-08-G06** (cache poisoning via Plan 04's load): Plan 04's `loadAndVerifyLicense` calls `invalidateLicenseCache()` after a successful activation; this plan ships the invalidation function (already exported from `src/main/license/index.ts` via Plan 01's status.ts).
- **T-08-GREP** (drift detection): Plan 06 ships `scripts/check-license-gate.cjs` + `tests/main/license/gate-coverage.test.ts`.
