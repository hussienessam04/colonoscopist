<objective>
Close G-08-2: after wizard completion, the license status cache must transition from `state: 'unactivated'` (pre-wizard) to `state: 'trial'` (post-wizard) without requiring an app restart. One-line source fix + one integration test case.

Purpose: the UAT Test 2 ("Fresh Install Starts 14-Day Trial") currently fails because `wizardBootstrap` writes `settings.trial_started_at` at `src/main/auth/index.ts:95` inside `db.transaction(...)` but does not invalidate the module-level memoized cache at `src/main/license/status.ts:25` (`let cached: LicenseStatus | null = null`). The cache was warmed at `app.whenReady()` before the wizard ran, so it holds `state: 'unactivated'` and the next `license.status` IPC returns the stale value. The renderer `LicenseGate` modal fires for `state==='unactivated'` and surfaces "Continue in trial" / "Activate now" buttons that should only render pre-wizard.

Output: `src/main/auth/index.ts` invalidates the cache post-commit (mirroring the precedent at `src/main/license/load-license.ts:117-119`) + a new RUN_SMOKE=1 integration test that warms the cache, runs the wizard, and asserts the next status read returns `state: 'trial'`.

</objective>
