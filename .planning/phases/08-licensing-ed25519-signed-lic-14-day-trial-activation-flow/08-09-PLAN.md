<objective>
Close G-08-3: LicenseGate modal fires on top of the wizard on first launch. The wizard IS the path to start the trial, so gating it with the activation modal is contradictory UX.

Fix shape chosen: Shape A — LicenseGate self-aware. LicenseGate already pulls `useRoute()` for the 'Activate now' navigate call at line 73. Widening that destructure to also pull `route` and adding `route.name !== 'wizard' && route.name !== 'login'` to the showModal predicate is the smallest change with zero new dependency.

Why not Shape B (App.tsx conditional wrapping): App.tsx already special-cases wizard/login for the auth-bootstrap redirect at lines 53-58, but that concern is route-redirect, not license show/hide. LicenseGate already owns the route dependency for its navigate call — keep the show/hide decision in the same component that owns the predicate.

Output: working wizard on first launch + 2 regression tests that would have caught this. 6 existing tests stay green.
</objective>
