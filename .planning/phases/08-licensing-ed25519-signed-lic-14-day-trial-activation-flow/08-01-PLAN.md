## Mitigations implemented by this plan

- **T-08-01, T-08-02** (tampered JSON / signature): `verifyLicense` operates on raw bytes; signature mismatch returns `{ valid: false, reason: 'SIGNATURE_MISMATCH' }`; the renderer-side error code is `IPC_LICENSE_INVALID` (Plan 04 wires the renderer error surface; Plan 01 ships the error code in `src/shared/errors.ts`).
- **T-08-03** (license theft): `computeMachineFingerprint()` reads CPU + MAC + disk serial on every verify call (cached in `status.ts` module-level after the first call); mismatch → `IPC_LICENSE_INVALID`.
- **T-08-04** (public key swap): `VENDOR_PUBLIC_KEY_HEX` is a module-level constant; the binary grep gate in Plan 06 catches drift.
- **T-08-05** (verify path replacement): `Object.freeze(_verifyLicense)` at module export; runtime assignment throws TypeError; the freeze assertion is in `verify.test.ts` (`Object.isFrozen(verifyLicense)`).
- **T-08-06** (trial clock): the verify path NEVER reads `settings.trial_started_at`; the column is wired in Plan 02 (separate plan, separate concern).
- **T-08-SC** (package legitimacy): already verified in RESEARCH §Package Legitimacy Audit; no new packages install that are not on the approved list.

## Mitigations deferred to later plans

- **T-08-07** (audit row on license events): Plan 04 wires `loadAndVerifyLicense` + `audit({ action: 'license.activated' | 'license.invalid' })`. The audit helper import path is in `verify.ts` JSDoc reference; the actual call sites are in Plan 04's `load-license.ts`.
- **T-08-IPC-GATE** (renderer bypass via direct IPC): Plan 03 wraps every `register*()` call with `licenseGated`; the exemption list includes `LICENSE_STATUS` + `LICENSE_ACTIVATE`. Plan 01 ships the IPC channel surface; Plan 03 ships the gate.
- **T-08-GREP** (drift in license gate coverage): Plan 06 ships `scripts/check-license-gate.cjs` + `tests/main/license/gate-coverage.test.ts`.
