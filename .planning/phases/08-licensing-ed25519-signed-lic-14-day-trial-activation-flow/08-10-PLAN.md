<objective>
Close G-08-4: when a gated IPC returns `{ok: false, code: 'IPC_LICENSE_INVALID'|'IPC_LICENSE_EXPIRED'}`, the renderer must not crash to a white screen. Instead, each gated IPC consumer renders an empty-state placeholder ("License required — open Settings → License to activate") while the LicenseGate modal stays interactable on top.

Root cause: `src/renderer/src/pages/PatientsList.tsx:88-89` destructures `res.rows` and `res.total` without checking `res.ok`. When the gate returns the failure shape, both are `undefined`, `setRows(undefined)` triggers a re-render, `rows.map()` crashes, React unmounts the entire tree, white screen. The same shape assumption is repeated across 7 other gated-IPC consumers. Plan 03 documented that the renderer SWR pattern would "branch on ok: false uniformly" — the discriminator was never implemented.

Fix shape (Shape B — centralized helper): `src/renderer/src/lib/ipc-result.ts` exports `safeInvoke<T>(p) → Promise<T | null>` that branches on the discriminated union. Each gated IPC consumer wraps its await with `await safeInvoke(window.api.X.Y(...))` and renders an empty-state placeholder if null. Future gated-IPC additions get the protection automatically.

Why Shape B over Shape A (per-call guards): the bug is that 8+ consumers each independently forgot to check the discriminator. A centralized wrapper makes the bug structurally impossible — calling code can't accidentally skip the check. Plan 03's documented intent ("the renderer SWR-style consumer pattern can branch on ok: false uniformly") is best honored by a uniform helper. The cost is one new file + 8 consumers; the benefit is no recurrence.

</objective>

**Step 1 — Create the safeInvoke helper:**

Create `src/renderer/src/lib/ipc-result.ts` with the minimal shape:

```ts
// ponytail: safeInvoke wraps gated IPC calls so the renderer never crashes
// when the main-process gate returns {ok: false, code: 'IPC_LICENSE_*'}.
// Per Plan 03: "Gate returns { ok: false, code: ... } as a return value (NOT
// a thrown IpcErrorException) so the renderer SWR-style consumer pattern
// can branch on ok: false uniformly". Plan 03 documented the contract;
// this helper enforces it at the call site.
//
// Returns T on success, null on gate rejection. Caller decides the
// empty-state UX (typically a card with 'License required — open Settings
// → License to activate').

export type IpcInvokeResult<T> = T | { ok: false; code: string } | null | undefined;

export async function safeInvoke<T>(p: Promise<IpcInvokeResult<T>>): Promise<T | null> {
  try {
    const res = await p;
    if (res == null) return null;
    if (typeof res === 'object' && 'ok' in res && res.ok === false) return null;
    return res as T;
  } catch {
    // Defensive: some IPC calls may still throw (e.g., IpcErrorException
    // from non-gated channels). Treat any throw as null — caller renders
    // empty state.
    return null;
  }
}
```
