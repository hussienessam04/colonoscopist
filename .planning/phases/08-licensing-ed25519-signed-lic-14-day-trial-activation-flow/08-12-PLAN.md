<objective>
Close G-08-6: the `useCaptureDeviceMap` hook (used by SettingsCapture + ProcedureRoom) calls `window.api.capture.listDevices()` without wrapping it in `safeInvoke`. When the license gate returns `{ok: false, code: 'IPC_LICENSE_*'}`, the destructured `dshowDevices` is the failure object, not an array, and downstream `dshow.find(...)` crashes. Plan 08-11 wrapped page-level IPC calls but missed the hook they depend on.

Root cause: `src/renderer/src/hooks/useCaptureDeviceMap.ts:22-37`:
```ts
void Promise.all([
  window.api.capture.listDevices(),  // ← gated, returns {ok:false} on expired
  navigator.mediaDevices.enumerateDevices(),
])
  .then(([dshowDevices, mediaDevices]) => {
    if (cancelled) return;
    setDshow(dshowDevices);  // ← dshowDevices = {ok:false, code:...}
    ...
  })
```

Fix shape: wrap `window.api.capture.listDevices()` with `safeInvoke(...)`. On null (gate rejection), set `dshow` to `[]` and `error` to a license-related message; downstream consumers render an empty device list gracefully.

Why this is the right scope: it's the SAME pattern as G-08-4 + G-08-5 fixes, applied to the missed hook. The fix is one file, ~5 lines. After this lands, the safeInvoke coverage is complete for the capture.* IPC surface; no further crashes expected.

</objective>

**Edit 1 — `src/renderer/src/hooks/useCaptureDeviceMap.ts`:**

1. Add import at the top:

2. Modify lines 22-37 to wrap the gated call. The fix preserves the success-path behavior (Promise.all structure) and adds a null-check branch:
   ```ts
   useEffect(() => {
     let cancelled = false;
     void safeInvoke(window.api.capture.listDevices())
       .then((dshowDevices) => {
         if (cancelled) return;
         if (dshowDevices === null) {
           // Plan 08-12 / G-08-6 — gate rejected. Surface as empty
           // device list + a license-aware error so SettingsCapture /
           // ProcedureRoom render an EmptyStateCard path instead of
           // crashing on dshow.find() downstream.
           setDshow([]);
           setError('License required — activate to list capture devices.');
           return;
         }
         return navigator.mediaDevices.enumerateDevices().then((mediaDevices) => {
           if (cancelled) return;
           setDshow(dshowDevices);
           setBrowser(mediaDevices.filter((device) => device.kind === 'videoinput'));
         });
       })
       .catch((cause: unknown) => {
         if (cancelled) return;
         setError(cause instanceof Error ? cause.message : 'Capture devices could not be listed.');
       })
       .finally(() => {
         if (!cancelled) setLoading(false);
       });
     return () => {
       cancelled = true;
     };
   }, []);
   ```

   Note: the previous code used `Promise.all([listDevices(), enumerateDevices()])` for parallel execution. The new code serializes (listDevices first, then enumerateDevices in the .then chain) to preserve the safeInvoke null check. The performance cost is negligible — these are sub-millisecond calls. If parallel execution matters later, safeInvoke can be composed with Promise.all inside, but YAGNI for now.
