## Trust Boundaries (Plan 02)

| Boundary | Description |
|----------|-------------|
| Test runner (Node) vs production runtime (Electron) | Tests stub `electron` via `vi.mock`. Mocks are honored inside the test process boundary only — production binary is unaffected. |
| CI grep-gate scripts vs filesystem | Each `check-*.cjs` reads from `src/**` and `package.json`; no write side effects. |
| Aggregate verifier (`verify-phase-1.cjs`) vs subprocesses | Spawns tsc, gates, and vitest sequentially. Failures halt; no parallel side effects. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation |
|-----------|----------|-----------|----------|-------------|------------|
| T-02-01 | TAMPERING / REPUDIATION | Grep-gate scripts silently pass on missing source | medium | mitigate | Each script verifies file existence with `fs.existsSync` first, exits non-zero with a printed filename if the target is missing. |
| T-02-02 | ELEVATION | Tests inadvertently import production `better-sqlite3` Database | low | mitigate | `tests/main/paths.test.ts` mocks `electron` (`getPath` only) — does not invoke `new Database(...)`. `tests/shell/auth-status.test.ts` mocks the renderer `contextBridge` and `ipcRenderer` — no DB on the test path. |
| T-02-03 | INFORMATION DISCLOSURE | Grep gate scripts leak source-file content to console | low | accept | Gates print only the filename + line number on failure, never the matched code. On pass they print a single short status line. |
| T-02-04 | DoS | Aggregate verifier spawns an infinite chain | low | mitigate | `verify-phase-1.cjs` uses bounded `spawnSync` array with explicit ordering — no recursion, no retry loops. |
| T-02-05 | TAMPERING (PROHIBITION) | SET-04 stub gate silently passes when a `users:*` IPC channel is added | medium | mitigate | `check-set04-stub.cjs` greps `src/shared/ipc-contract.ts` for the literal `'users:'` substring AND `fs.existsSync('src/main/ipc/users.ts')` — both must hold for the script to pass. |
